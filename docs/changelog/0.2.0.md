# v0.2.0 - throwing fixes

> **Upgrading from 0.1.5:** just replace the jar. Your config carries over.
> One behaviour change: right-clicking a chest, door or other block while holding a throwable now
> throws it without using the block. Put the item away (or switch slots) to open the block.

- **Throwables are only ever thrown.** Right-clicking with a throwable no longer also does what the
  plain item would do: a Bomb is no longer placed as a head (which turned it into an ordinary head),
  a fire charge no longer lights a fire as well as being thrown, and the Grappling Hook no longer
  starts loading your arrows into the crossbow. This also holds while the item is on cooldown.

- **Protected areas are respected.** Where a protection plugin (WorldGuard, Towny, GriefPrevention...)
  doesn't allow using items, nothing is thrown. If another plugin cancels a hit, the throwable's
  effect no longer goes off anyway.

- **Grappling Hook fixes.**
  - Stopping or crashing the server mid-grapple no longer leaves an invisible, invulnerable chicken
    in the world.
  - After a grapple, only the Grappling Hook itself is reloaded, with one arrow. Before, any
    crossbow moved into that hotbar slot got a free arrow.

- **Thrown models clean up properly.** The 3D models some throwables show in flight are always
  removed when they land, including when thrown point-blank into a block, and two throwables in the
  air can no longer remove each other's model.

- **`/yeetables give` with a full inventory** drops the item at your feet instead of deleting it.

- **Better help.** `/yeetables` and `/yeetables help` show the version, a short description, the
  commands, and links to the GitHub repo and the Discord.

- **Tested on Minecraft 26.x.** Every change is now checked on Paper and Purpur 1.21.11, 26.1.2,
  26.2 and 26.3.
