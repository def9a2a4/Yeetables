# v0.2.1 - quieter logs

> **Upgrading from 0.2.0:** just replace the jar. Your config carries over.

- **"Unknown yeetable ID" warns once.** A thrown item whose yeetable has since been removed from the
  config used to log a warning every time one hit something. It now warns once per missing ID.

- **Quieter startup and shutdown.** Removed the "Yeetables enabled." and "disabled." lines. The
  server already prints its own line when each plugin is enabled or disabled. The "Loaded N custom
  items and N yeetables" line stays.
